# Skin Cancer Detection

A deep learning web application for detecting and classifying skin lesions using YOLO and Django.

## About the Project

This project focuses on using deep learning and computer vision to assist in the detection of skin lesions from medical images.

The system uses YOLO-based object detection to identify skin lesions and classify them as benign or malignant. A Django web application was developed to provide a simple interface for uploading an image and viewing the prediction.

## Technologies Used

- Python
- YOLO
- Deep Learning
- Computer Vision
- Django
- CNN
- Image Processing

## What I Worked On

- Preprocessed and prepared skin lesion images for model training
- Worked with deep learning and CNN-based approaches
- Implemented YOLO-based lesion detection
- Worked on benign and malignant lesion classification
- Developed the Django web application
- Integrated the trained model with the web application
- Evaluated the model using test images
